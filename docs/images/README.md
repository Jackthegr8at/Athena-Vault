## Refreshing captures

Use only the synthetic demo session and verify its read-only indicator before capturing. Never use an operator account, a private deployment backup, or personal financial records. Wait for fonts, visible artwork, and charts to finish loading. Capture the browser content without browser chrome, addresses, credentials, or developer tools. Do not edit displayed balances or fabricate interface states for a screenshot.

Review every image for private names, records, addresses, and broken or unfinished visible content before replacing it. Keep only these selected captures, update the capture date in the root README, and check every relative image link.
